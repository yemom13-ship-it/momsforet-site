이미지 넣는 방법

1. 이 폴더에 아래 파일명을 그대로 넣으면 해당 사진 영역에 자동 표시됩니다. JPG 권장, WebP도 가능하지만 아래 기본 경로는 .jpg로 지정되어 있습니다.
2. 예: hero.jpg, nursery.jpg, mother-care.jpg, room-main.jpg
3. 파일명은 각 페이지 HTML의 data-photo="assets/images/파일명.jpg"를 수정해 바꿀 수 있습니다.
4. 권장 크기: 메인 이미지 가로 1800px 이상, 카드 이미지 가로 1000px 이상. 사진은 가급적 실제 시설에서 촬영한 사진을 사용하세요.
5. 자세한 전체 이미지 파일명 목록은 README-KO.md를 확인하세요.
